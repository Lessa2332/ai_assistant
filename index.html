Крок 1. API Ключ

Введіть ваш Gemini API Key. Він зберігається лише у вашому браузері та не передається третім особам.

Крок 2. Фото завдання

Завантажте фото завдання або зробіть знімок камерою. Вкажіть клас, предмет і тему. AI сформує ключ відповідей.

Крок 3. Перевірка ключа

Перегляньте згенерований ключ, за потреби відредагуйте бали та відповіді. Підтвердьте перехід до перевірки робіт.

Крок 4. Результати

Завантажте роботи учнів. AI виставить бали, рівень, помилки та поради. Експортуйте у CSV, Word або PDF.
